## Cara Menjalankan Aplikasi

1. Buka **Android Studio**.
2. Pilih atau buka project Android yang sesuai dengan modul praktikum.
3. Pastikan Android SDK dan konfigurasi project telah tersedia.
4. Hubungkan perangkat Android atau gunakan emulator.
5. Jalankan aplikasi melalui tombol **Run** pada Android Studio.
6. Sesuaikan source code dan konfigurasi dengan modul praktikum yang sedang dikerjakan.
